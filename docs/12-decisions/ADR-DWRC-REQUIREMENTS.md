# Durable Workflow Decision Record Requirements

Status: Proposed Decision Set  
Version: 1.0.0  
Work Package: `SECB-WP-ENGLOOP-003`

The following ADRs must be approved before runtime implementation passes Architecture Gate:

| ADR | Decision |
|---|---|
| `ADR-DWRC-001` | Durable workflow engine and BST portability boundary |
| `ADR-DWRC-002` | Canonical history store, partitioning and consistency model |
| `ADR-DWRC-003` | Deterministic workflow coding and replay standard |
| `ADR-DWRC-004` | Side-Effect Gateway, idempotency and reconciliation protocol |
| `ADR-DWRC-005` | Compensation registry, ordering and authorization model |
| `ADR-DWRC-006` | Snapshot, event/schema evolution and workflow patching |
| `ADR-DWRC-007` | Evidence payload storage, retention and integrity anchoring |
| `ADR-DWRC-008` | Resilience topology, backup, RPO and RTO |

Each ADR records alternatives, decision drivers, threat/security impact, data/retention impact, migration/rollback path, acceptance tests, authority, ballot result and supersession relationship.
