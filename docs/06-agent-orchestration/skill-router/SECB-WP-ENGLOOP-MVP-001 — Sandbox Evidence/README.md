# SecB Engineer Loop v1.5 Sandbox MVP

Side-effect-free reference implementation for `SECB-WP-ENGLOOP-MVP-001`.

Run:

```bash
cd sandbox_mvp
python -m unittest -v test_router.py
```

The code validates only the Skill Router control semantics covered by FIT-101–120. It does not install or invoke real skills, access credentials, call external systems, authorize production effects or certify the full Engineer Loop runtime.
