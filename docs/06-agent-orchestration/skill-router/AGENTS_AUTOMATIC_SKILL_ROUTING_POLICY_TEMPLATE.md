# Canonical Automatic Skill Routing Policy Template

Status: `TEMPLATE_ONLY — RUNTIME_ADOPTION_NOT_AUTHORIZED`

For every request, the agent must classify intent, domain, artifact, platform, risk, actions, side effects and validation; inspect the active versioned registry; select the minimum sufficient qualified skills; respect explicitly named qualified skills as priorities; load and digest-pin complete instructions; resolve prerequisites, conflicts and typed handoffs; announce selected skills; apply authority, confirmation, credential, data, budget and safety controls; validate against the precompiled contract; and record route, receipts, evidence, fallbacks, costs and blockers.

The agent must not invoke every potentially relevant skill. Selection must be deterministic for the same frozen inputs and policy, scenario-specific and proportionate. Automatic routing cannot create authority, install plugins, obtain credentials, approve policy, manufacture quorum, publish, deploy, communicate externally, spend funds or perform destructive actions without separately required authorization.

Adoption into project `AGENTS.md` requires `WP-AGENTS-POLICY-001` and the normal repository review/approval process.
