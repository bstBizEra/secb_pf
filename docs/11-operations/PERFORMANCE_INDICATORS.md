# Closed-Loop Performance Indicators

Status: Draft
Work Package: `SECB-WP-FWK-001`

| Layer | Suggested KPIs |
|---|---|
| Engineer Loop | Lead time, first-pass success, defect escape rate, rework rate |
| Quality | Test coverage, review findings, escaped defects, security finding severity |
| Cost | Tokens, tool calls, compute cost, cost per accepted change, budget exceptions |
| Learn Loop | Lessons extracted, validated-learning rate, rejection rate, time to validation |
| Knowledge | Retrieval precision, freshness, conflict rate, duplication rate, stale-use incidents |
| Skills | Invocation success, routing accuracy, benchmark improvement, rollback frequency |
| Governance | Unauthorized-action rate, evidence completeness, gate exceptions, SoD violations |
| Business | Deployment frequency, reliability, value-delivery time, outcome realization |

## Measurement Rules

- Every KPI requires an owner, formula, source, cadence, target, and guardrail.
- Cost efficiency must not override safety, quality, or authorization controls.
- KPI changes must be versioned so trend comparisons remain interpretable.
- High performance is not inferred from activity volume alone; accepted outcomes and stakeholder value are required.
